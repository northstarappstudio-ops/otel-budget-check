# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue. Report privately to
northstarappstudio@gmail.com with details:

- Affected version
- Steps to reproduce
- Impact

We aim to acknowledge reports within 5 business days.

## Scope

- The GitHub Action code in this repository (`src/`, `entrypoint.sh`, `Dockerfile`).
- No servers, services, or accounts are operated as part of this project.
